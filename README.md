# Fantasy Cricket Game

A simple Fantasy Cricket Game implemented in Python. The game allows users to create their own fantasy cricket team by selecting players from a list, and it simulates the team's performance based on predefined player statistics.

## Features

- **Player Selection**: Users can select players for their fantasy team based on their roles (Batsman, Bowler, Wicketkeeper, Allrounder).
- **Match Simulation**: Simulates a match and calculates the total points for the fantasy team based on player performance (runs, wickets, catches).
- **Dynamic Scoring**: Points are calculated for each player based on their real-life match stats (can be customized).
- **Team Management**: Users can create and manage their fantasy cricket team.

## Technologies Used

- Python 3.x
- Random module for match simulation
- Optional: CricAPI for fetching live cricket stats (if integrated)
